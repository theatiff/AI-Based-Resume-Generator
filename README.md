# AI-Based Resume Generator

## **1. Project Overview**

The **AI-Based Resume Generator** is an AI-powered web application designed to simplify and improve the resume creation process. It helps users generate professional, well-structured resumes by providing their personal, educational, and professional information through a simple text prompt.

Instead of manually writing every section of a resume, users can enter their details, describe their qualifications, mention their technical skills, provide work experience, list academic projects, and share other relevant information. The application processes this input using an Artificial Intelligence model and generates organized resume content based on the information provided.

One of the main features of this project is its **Interactive Resume Editing Dashboard**. Unlike basic resume generators that only produce automatically generated content, this application allows users to review the generated resume and make changes directly through an editable interface. Users can modify their personal information, update skills, rewrite descriptions, add or change experience details, and customize the generated content according to their requirements.

The application combines AI-powered content generation with manual editing capabilities, giving users both automation and control over their final resume.

The project uses **React.js and Tailwind CSS** for the frontend, **Spring Boot and Java** for backend development, and **DeepSeek-R1 through Ollama** for AI-powered resume generation.

## **2. Project Objectives**

The main objectives of this project are:

* To reduce the time and effort required to create a professional resume.
* To use Artificial Intelligence to generate structured resume content from simple user prompts.
* To make resume creation easier for students, fresh graduates, and job seekers.
* To provide an editable dashboard where users can modify AI-generated information.
* To allow users to maintain control over the content generated by the AI model.
* To combine frontend and backend technologies with locally hosted AI model integration.
* To create a user-friendly platform that makes resume preparation more accessible.

## **3. Key Features**

### **3.1 AI-Powered Resume Generation**

The application uses Artificial Intelligence to generate resume content based on the information supplied by the user.

Users can provide details such as:

* Full name and contact information.
* Educational qualifications.
* Technical and professional skills.
* Work experience and internships.
* Career objectives and professional summaries.

The AI model processes the given prompt and generates organized resume content using the information provided.

### **3.2 Prompt-Based Input System**

Users can describe their background and qualifications through a text prompt rather than manually filling out every resume section.

The application takes the provided information and sends it to the backend for AI processing.

This makes the resume creation process more flexible because users can describe their information in their own words.

### **3.3 AI-Generated Resume Content**

After processing the user's input, the AI model generates structured content suitable for different sections of a professional resume.

The generated content can include:

* Professional Summary
* Career Objective
* Education
* Technical Skills
* Work Experience
* Internship Experience
* Projects
* Certifications
* Achievements

The generated information is based on the details supplied by the user.

### **3.4 Interactive Editable Dashboard**

The editable dashboard is one of the most important parts of this application.

After the AI generates the resume, the content is presented through an interactive dashboard where users can review and modify the generated information.

Users can:

* Edit their personal information.
* Update their professional summary.
* Modify educational details.
* Add or change technical skills.
* Edit project descriptions.
* Update work and internship experience.
* Correct or rewrite AI-generated content.
* Customize resume sections according to their needs.

This feature ensures that users are not restricted to the first version generated by the AI.

### **3.5 User-Controlled Content Modification**

AI-generated content may sometimes require corrections or additional information.

To address this, the application allows users to manually review and modify the generated content.

Users can improve descriptions, correct mistakes, add missing details, and make their resumes more relevant to their career goals.

### **3.6 Frontend and Backend Integration**

The application follows a frontend-backend architecture.

The React frontend handles user interaction, prompt submission, and resume editing.

The Spring Boot backend handles API requests, processes user input, and manages communication with the AI model.

This separation makes the application easier to organize and maintain.

### **3.7 AI Model Integration**

The project integrates the DeepSeek-R1 model through Ollama.

Ollama provides the environment to run the AI model, while the backend communicates with it to process prompts and generate resume content.

This integration allows the application to use AI capabilities without depending entirely on a third-party hosted AI API.

## **4. How the Application Works**

The application follows a step-by-step process to generate and edit resumes.

**Step 1: Enter Personal Information**

The user provides relevant details about their background, education, skills, experience, projects, and career objectives.

**Step 2: Submit the Prompt**

The user submits the information through the application's input interface.

**Step 3: Frontend Request Processing**

The React frontend collects the user's information and sends a request to the Spring Boot backend through a REST API.

**Step 4: Backend Processing**

The Spring Boot application receives the request and prepares the input for AI processing.

**Step 5: AI Model Communication**

The backend communicates with Ollama, which runs the DeepSeek-R1 model.

The model processes the user's information and generates structured resume content.

**Step 6: Resume Generation**

The generated content is returned to the backend and then sent to the frontend.

**Step 7: Display Generated Resume**

The application displays the generated resume information in an editable dashboard.

**Step 8: Edit and Customize**

Users can review the generated information and make changes wherever necessary.

**Step 9: Final Resume Preparation**

After editing, users can review their updated resume content and prepare their final version.

## **5. System Architecture**

The application is divided into three main components.

### **Frontend Layer**

The frontend is developed using React.js, Vite, and Tailwind CSS.

Its responsibilities include:

* Providing the user interface.
* Collecting information through prompts.
* Sending requests to the backend.
* Displaying AI-generated resume content.

### **Backend Layer**

The backend is developed using Java and Spring Boot.

Its responsibilities include:

* Receiving frontend API requests.
* Processing user-provided information.
* Managing communication with the AI model.
* Handling resume generation requests.
* Returning generated resume content to the frontend.

### **AI Processing Layer**

The AI processing layer uses Ollama and DeepSeek-R1.

Its responsibilities include:

* Processing user prompts.
* Understanding the supplied resume information.
* Generating structured resume content.
* Returning AI-generated output to the backend.

## **7. API Integration**

The application uses REST API communication between the React frontend and Spring Boot backend.

The resume generation functionality is handled through the backend API.

**Resume Generation Endpoint:**

```http
POST /api/v1/resume/generate
```

This endpoint accepts user-provided resume information, processes the request through the AI integration, and returns the generated resume content.

The frontend uses the API response to display the generated information in the editable dashboard.
